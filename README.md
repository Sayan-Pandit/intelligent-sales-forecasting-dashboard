# Intelligent Sales Forecasting Dashboard

An upcoming Python-based dashboard project for analyzing historical sales data and forecasting future sales using machine learning models.

## Technologies
- Python
- Pandas
- Prophet
- Random Forest
- XGBoost
- Plotly
- Streamlit

## Planned Features
1. Sales Dashboard
2. Monthly Sales Trends
3. Product-wise Sales Analysis
4. Regional Sales Analysis
5. Future Sales Prediction
6. Interactive Charts
