# Intelligent Sales Forecasting Dashboard

An initial Python project scaffold for building an intelligent sales forecasting dashboard with data analysis, forecasting models, and interactive visualizations.

## Technologies
- Python
- Pandas
- Prophet
- Random Forest (scikit-learn)
- XGBoost
- Plotly
- Streamlit

## Planned Features
1. Sales Dashboard
2. Monthly Sales Trends
3. Product-wise Sales Analysis
4. Regional Sales Analysis
5. Future Sales Prediction
6. Interactive Charts
